# ✨ Vibely — Social Vibe Network

> **Feel the Pulse, Share the Vibe.**  
> Vibely is a modern, glassmorphic social vibe & mood sharing network where music, visual aesthetics, and emotional frequencies connect.

---

## 🌟 Key Features

- **Dynamic Vibe Stream**: Share thoughts, mood frequencies, attached soundtracks, and aura color cards.
- **Mood Check-in & Frequency Radar**: Real-time mood telemetry (Deep Flow ⚡, Chill & Lo-Fi 🌙, Creative Spark 🎨, Hyped Energy 🔥) that dynamically recalibrates your community resonance.
- **Synthesized Ambient Audio Lounge**: Built-in harmonic Web Audio synthesizer playing relaxing ambient chords & polyphonic textures with an animated real-time canvas visualizer.
- **Aura & Palette Customizer**: Select mood tones and gradient card halos when dropping vibes.
- **Interactive Reactions**: Vibe checks (💜), Energy boosts (⚡), commentary threads, and link sharing with toast feedback.
- **Multi-Theme Engine**: Seamless toggle between *Velvet Dark*, *Cyber Neon*, and *Sunset Amber* aesthetic themes.
- **100% Vanilla Tech Stack**: Pure HTML5, CSS3, and JavaScript — lightning-fast load times with zero dependencies or complex build steps.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with any local static HTTP server:

```powershell
# Using Python
python -m http.server 3000

# Or using npx serve
npx -y serve .
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
